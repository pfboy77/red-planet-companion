# Release Notes

## iOS v1.0.0（提出用下書き）

初回のネイティブiOSリリースです。

### Highlights

- SwiftUIによるiPhone / iPad対応の資源・産出量・Terraform Rating管理
- 端末内保存、単独プレイ、産出フェーズ、Undo / Redo
- 任意の同一ネットワーク・マルチプレイ接続
- 切断後の再接続、競合時の状態同期、退出時の単独プレイ復元
- ローカルネットワーク利用理由とプライバシー宣言を含む提出設定

### Notes

ローカル対戦には、別途同一ネットワーク上で起動した対応サーバーが必要です。本アプリは非公式のファンメイド補助ツールです。

## Web v0.1.0

Initial public release of Red Planet Companion, a fan-made single-player strategy board game companion built with React and TypeScript.

### Highlights

- React + TypeScript frontend
- Single-player resource management
- Terraform Rating tracking
- Resource production phase
- Undo / redo support
- Browser localStorage persistence
- Responsive web UI

### Notes

This is an unofficial fan-made project for learning and experimentation.
