# iOS リリース・チェックリスト

このリポジトリで完了できる提出準備と、Apple Developer / App Store Connect で所有者が行う手順を分けています。アプリのバージョンは現在 `1.0 (1)`、最低対応OSは iOS 17.0 です。

## リポジトリで完了済み

- 不透明な 1024×1024 の App Store 用アイコンを `AppIcon` に登録
- `PrivacyInfo.xcprivacy` を追加し、端末設定保存（UserDefaults）の Required Reason API を `CA92.1` として宣言
- アプリ表示名、ローカルネットワーク利用理由、輸出コンプライアンス回答、画面回転を明示した `Info.plist` を追加
- 任意のローカルサーバー接続以外の ATS 例外と、複数ウインドウを無効化
- 切断・再接続・競合時の再試行・退出・マルチプレイ中の Undo/Redo 無効化を実装し、回帰テストを追加
- Release build、unsigned archive、iPhone/iPad の自動テストを実行（実行結果は提出直前に再確認する）

## App Store Connect で必要な作業

1. Apple Developer の App ID と App Store Connect のアプリレコードを、現在の Bundle ID `hoshino.teraformingmars2` で確認または作成します。別のBundle IDにする場合は、先にXcode設定と記載を変更します。
2. App Store Connect でSKU、アプリ名、カテゴリ、年齢区分、価格・配信地域、著作権表記を入力します。下書きは [APP_STORE_METADATA.md](APP_STORE_METADATA.md) にあります。
3. 公開済みのサポートURLとプライバシーポリシーURLを用意します。テンプレートは [PRIVACY_POLICY.md](PRIVACY_POLICY.md) ですが、運営者名・連絡先・公開URLを実値に置換してから公開してください。
4. iPhone と iPad の提出要件を満たす実機またはシミュレータのスクリーンショットを撮影し、App Store Connect に追加します。リポジトリ内のWeb画面キャプチャは使用しません。
5. 実機で署名済み Archive を作成し、TestFlightへアップロードします。ビルド番号はアップロードごとに増やします。
6. App Privacy、輸出コンプライアンス、コンテンツ権利、レビュー連絡先を実際の運営内容に基づいて回答します。ローカル対戦サーバーのホスト・運用主体も回答とプライバシーポリシーに合わせます。

## 提出前の実機確認

- iPhone と iPad で単独プレイ、保存・復元、産出フェーズ、TR変更、画面回転を確認する
- 同一Wi-Fi上のサーバーに `ws://<LAN IP>:8080/ws` で接続し、作成・参加・退出・バックグラウンド復帰を確認する。`localhost` はiPhone自身を指すため使わない
- ローカルネットワークの許可ダイアログを拒否した場合に、単独プレイが継続して利用できることを確認する
- 2台以上で同じセッションを操作し、競合時に状態がサーバー側へ収束することを確認する
- TestFlight配布版でクラッシュ、表示名、アイコン、プライバシーポリシー導線を確認する

## 重要な留意点

- このアプリは単独プレイだけで使用できます。ローカル対戦は、利用者または運営者が同一ネットワーク上で別途起動するサーバーへの任意接続です。
- `NSAllowsLocalNetworking` はローカルサーバー接続のために最小限で設定しています。実際に配布するサーバー形態・URLに合わせ、実機でATS接続を確認してください。
- 本プロジェクトは非公式のボードゲーム補助アプリです。名称、素材、ゲーム要素、説明文をストアに提出する前に、商標・著作権・利用許諾を権利者または法務担当者へ確認してください。
- Appleアカウントへの署名、アップロード、審査提出はリポジトリ操作では完結しないため、本作業では実行していません。
