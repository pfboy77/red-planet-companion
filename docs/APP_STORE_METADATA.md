## 説明文（日本語）

Red Planet Companion は、資源・産出量・Terraform Rating を記録するための非公式ゲーム補助アプリです。ソロモードでは資源の増減、産出フェーズ、TR、保存・復元、Undo/Redoを端末内で利用できます。

マルチプレイでは利用者が登録した対応サーバーへ接続し、各プレイヤーの資源状況を共有できます。同一LANでは `ws://`、インターネットでは `wss://` を使用します。対応サーバーの別途用意が必要です。複数のサーバーを登録でき、iOSではサーバーごとに再接続情報を保存します。

本アプリは非公式のゲーム補助ツールであり、権利者による承認・提携・後援を示すものではありません。

キーワード候補: 資源管理、ボードゲーム、マルチプレイ、ゲーム記録、戦略

## App Review用メモ

アカウント登録はありません。ソロは通信なしで使用できます。ホームから「アプリ情報」を開くとバージョン、プライバシーポリシー、サポート、ライセンス、保存データ削除があります。

### ソロの確認

1. 起動して「ソロモードを開始」を選択。
2. 各資源の増減と産出量を変更し、「産出」を実行。TRの増減とUndo/Redoを確認。
3. 終了して再起動し、ソロを開始して保存状態を確認。
4. ホーム→アプリ情報→この端末の保存データを削除を確認して実行し、初期状態へ戻ることを確認。

### マルチプレイの確認

**リリース阻害事項: 審査期間中に利用可能な対応サーバーと、下記の具体情報が未確定です。ソロ確認だけでマルチプレイも検証できるとは案内しないでください。**

```text
Server name: [審査用サーバーの表示名]
WebSocket URL: [稼働する審査用wss:// URL]
Authentication: [実運用の接続認証要否と具体手順。現行アプリに任意HTTP認証の入力機能はない]
Steps to create/join:
  ホーム→サーバーを管理→追加→名前とURLを保存して選択。
  表示名を入力し、フレンド／プライベートを選んでルーム作成。
  別の端末で同じサーバーを登録し、表示名・Session ID・Join codeを入力して参加。
Expected behavior:
  両端末の資源・産出量・TRが同期し、他プレイヤー画面に表示される。
  切断後に再接続でき、Privateの再接続トークンはアプリが自動保存する。
```

LANで審査する場合は、対応サーバーの起動手順（server/README.md）、到達可能なLAN IP、ネットワーク条件を明示し、担当者が利用できることを確認します。レビュー連絡先も所有者が記入してください。

## App Privacy: 運用形態ごとの提出判断

### 利用者運営サーバーのみ

開発者がサーバーデータを受領しない運用を維持する場合、その事実、利用者指定サーバーへの通信、端末内保存を区別して説明します。ホスティング、サポートサイト、ログ、追加SDKも確認した上で、App Store Connectの提出時の定義に従って回答します。「収集なし」を自動的な結論にしません。

### 開発者運営サーバーを提供する場合

表示名、クライアント／プレイヤー識別子、ゲームプレイ内容、接続ログなど開発者が受領・保持するデータとアプリ機能目的との関係を確認し、App Privacyを再評価します。保持・削除手順と受領主体をプライバシーポリシーへ追記し、`NSPrivacyCollectedDataTypes` も再確認します。現在の空の宣言を根拠なく流用しません。
